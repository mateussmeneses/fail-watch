FailWatch — Opcoes

Configure o que conta como falha e como os dados sao guardados.

Requisicoes com status maior ou igual a este valor sao gravadas. Ex.: 400 captura erros de cliente e servidor; 500 captura apenas erros de servidor.
Inclui requisicoes que falharam sem resposta HTTP (DNS, CORS, offline, timeout, abort).
Ao ultrapassar, as falhas mais antigas sao descartadas.
Corpos maiores sao truncados para economizar espaco. O tamanho original fica registrado.
Substitui o valor destes headers por «redacted» antes de guardar. Importante ao compartilhar dumps.
Usa a API webRequest para capturar falhas que a interceptacao de fetch/XHR nao ve (ex.: fora do contexto da pagina). Nao traz o corpo da resposta. Ao ligar, recarregue a extensao.
Limite a captura a certos dominios. "Todos" captura tudo; "Allowlist" so os padroes listados; "Denylist" tudo menos os listados.
Um padrao por linha. Use * como coringa. Ex.: *.meu-app.com, api.exemplo.com
Tira uma screenshot da aba visivel quando uma falha ocorre. Util para contexto no bug. So funciona com a aba ativa/visivel.
